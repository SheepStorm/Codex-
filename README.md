# Focus Up (Codex-)

A lightweight single-page brain-training web app implemented in plain HTML/CSS/JavaScript.

## Overview

This project runs entirely in the browser from a single `index.html` file and provides:

- A landing page and training list flow.
- Multiple visual/attention training modes.
- A dark, game-like UI optimized for full-screen interaction.

## Run locally

Because this is a static app, you can run it with any simple web server.

### Option 1: Python

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

### Option 2: Open file directly

You can also open `index.html` directly in a browser, though a local server is recommended for consistent behavior.

## Project structure

- `index.html`: Application markup, styles, and behavior.
- `README.md`: Project documentation.

## Notes

- No build step is required.
- No external dependencies are required.
